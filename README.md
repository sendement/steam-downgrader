# steam-downgrader

Графическая программа для отката установленных игр Steam на старые сборки и защиты
от того, чтобы Steam обновил их обратно. Вся «магия» консоли `download_depot` и ручного
копирования файлов собрана в одно окно.

```
uv tool install -e ~/steam-downgrader   # команда steam-downgrader в PATH
steam-downgrader                        # GUI
steam-downgrader list | versions <appid> | relock | unlock <appid> [--validate] | service install|remove
```

## Как пользоваться

1. Выберите игру слева. В «Версиях» — все сборки, о которых знает эта машина.
   При первом выборе игры открывается её страница манифестов на SteamDB и окно импорта:
   выделите таблицу (даты + ID), Ctrl+C, вставьте — версии запомнятся, и в следующий раз
   будут в списке сразу. Повторить/дополнить (в т.ч. для DLC-депо) — «Импорт версий со SteamDB».
   Можно и просто вписать ID манифеста в колонку «Целевой манифест».
2. **Скачать выбранную версию**:
   * *Консоль Steam* (по умолчанию, без логина): окно выдаёт команды
     `download_depot …` → «Копировать» → вставить в `steam://open/console`.
     Прогресс и завершение программа видит сама (по размеру папки и `console_log.txt`).
   * *DepotDownloader* (в настройках; можно скачать с GitHub одной кнопкой):
     всё автоматически, вход QR-кодом или логином; токен запоминает сам DepotDownloader.
3. **Откатить и защитить**: Steam закрывается, файлы старой сборки переносятся в папку
   игры, файлы, которых в старой сборке не было, удаляются, и включается защита.

«Защитить текущую версию» просто замораживает игру на установленной сборке.

## Откуда берутся версии

У Valve нет публичного API со старыми манифестами, поэтому используются только локальные источники:

| Источник | Что даёт |
|---|---|
| `appcache/appinfo.vdf` | текущие сборки всех веток (public, беты, иногда `previous_version`) |
| `logs/content_log.txt` | строки `finished update … (BuildID …)`: сборки, которые ставил этот Steam |
| `depotcache/*.manifest` | каждый скачанный манифест с датой сборки; из них восстанавливаются старые версии («восстановлено») |
| `logs/console_log.txt` | завершённые `download_depot` |
| импорт со SteamDB | вставленная таблица манифестов депо (SteamDB не отдаёт её скриптам, поэтому через буфер обмена) |
| `~/.local/share/steam-downgrader/state.json` | снимки установленных сборок при каждом запуске программы и вручную введённые ID |

Программа ведёт собственную историю, поэтому со временем версий становится больше.

## Как устроена защита

Steam решает, что игра устарела, сравнивая `appmanifest_<appid>.acf` (buildid и манифест
каждого депо) с текущей сборкой ветки. После отката программа:

* записывает в `.acf` **актуальные** buildid и манифесты из `appinfo.vdf`: Steam считает,
  что обновлять нечего; реальные (старые) манифесты хранятся в `state.json`;
* ставит `AutoUpdateBehavior = 1` («обновлять только при запуске»);
* делает `.acf` только для чтения;
* опция **сильная защита**: вся папка игры только для чтения. Если Steam всё-таки начнёт
  обновление, оно упадёт с ошибкой записи и не перезапишет файлы. Игры, которые пишут
  в свою папку, могут на это ругаться.

При выходе новой сборки подмена отстаёт: `relock` подтягивает её к новому buildid.
Он запускается при каждом старте программы, а флажок **Авто-relock** в тулбаре ставит
systemd-юнит (`steam-downgrader-relock.path`), который запускает его каждый раз,
когда Steam обновляет `appinfo.vdf`.

### Ограничения, о которых стоит знать

* Steam читает `.acf` при старте. Если он узнал о новой сборке, пока был запущен,
  то до перезапуска может считать игру устаревшей и захотеть обновить её при запуске.
  После relock **перезапустите Steam** (программа напишет об этом в лог).
* «Проверить целостность файлов» в Steam вернёт актуальную версию. Так же работает и
  «Снять защиту → вернуть актуальную версию».
* Для применения и защиты Steam должен быть закрыт; программа закроет его сама.
* `download_depot` и DepotDownloader качают только то, чем владеет аккаунт.
* Онлайн-игры и игры с античитом могут не пустить на старой версии.

uv sync
